<일러스트 요청사항>
일러스트 해상도는 따로 정해드리진 않고, 그려주신 일러스트를 psd 파일에 있는 배경에 클리핑 마스크로 잘라서 쓸 것 같습니다. 보내드린 psd 파일 확인하시면 될 것 같습니다.

하나의 일러스트로 카드 일러, 유닛 일러 모두 사용할 것 같습니다.

가능하시면 한 항목 당 (원본 일러스트 + 원본 일러스트를 각 ui psd 파일에 클리핑 마스크를 적용한 psd 파일) 이렇게 주시면 감사드립니다. 어려우시다면 원본 일러스트만 주셔도 괜찮습니다.

illust_sample : 카드 일러스트 샘플
card_image.psd : 카드 ui 파일

arona_icon.png : 아로나 영웅 능력 일러스트 샘플
arona_image.psd : 아로나 영웅 능력 ui 파일

sensei_sample.png : 선생 영웅 일러스트 샘플
sensei_image.psd : 선생 ui 파일

ui_board.png : 유닛 일러스트 샘플
unit_image.psd : 유닛 ui 파일

최종.psd : 필드 전채 ui 파일
카드.psd : 카드 전체 ui 파일



1. 선생
하스스톤의 영웅에 해당하는 이미지입니다.

최종.psd 파일의 우 상단과, 좌 하단의 평행사변형 ui에 들어갈 이미지입니다.

구도는 어깨 아래까지 살짝 나오는 흉상으로 생각하고 있습니다.

아군 영웅 : 선생
애니판 선생 말고, 공식에 등장한 선생 일러가 없으므로 tv 애니에 나온 선생을 모티브로 그려주시면 될 것 같습니다.

배경은 밝은 하늘색으로 단색 배경이나, 구름이 살짝 있는 밝은 야외 배경으로 생각하고 있습니다,

적 영웅 : 프레나파테스
인게임에 나오는 프레나파테스 이미지를 모티브로 그려주시면 될 것 같습니다.

배경은 아군 영웅과 대비되는 어두운 파란색으로 생각하고 있습니다.

2. 아로나 / 프라나
하스스톤의 영웅능력에 해당하는 이미지입니다.

사용 가능하면 싯딤의 상자가 켜지고, 사용 후에는 싯딤의 상자의 전원이 꺼지는 컨셉입니다.

구도는 아래 능력에 맞게 부탁드립니다. 같은 영웅 능력은 같은 구도에 아로나 프라나로만 구분하면 될 것 같습니다.

능력 : 아군 유닛을 주변 한 칸 이동시킵니다.

아군 영웅 능력 : 아로나

적군 영웅 능력 : 프라나

3. 카드
하스스톤의 하수인에 해당하는 카드입니다.
동아리 (엔지니어 부) 효과는 롤토체스의 시너지 효과와 같은 역할입니다.

시라하시 우타하 - 엔지니어부 (필드에 있는 엔지니어 부원 수만큼 아군 기계 유닛에게 1/1 부여)
능력 : 천둥이 (1/1) 소환

컨셉은 기계를 제작하는 마이스터 동아리를 게임 내에서 기계 소환 -> 강화하는 어그로 컨셉의 동아리로 구현해보았습니다. 우타하의 경우 작 중에서 시그니처 발명품인 천둥이를 소환하는 것을 컨셉으로 잡았습니다.

총 선생 2장 (선생, 프레나파테스) + 아로나 2장 (아로나, 프라나), 카드 1장 (시라하시 우타하) 5장입니다.

감사합니다!
