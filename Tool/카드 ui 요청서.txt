카드에 표시되어야하는 정보
- 카드 이름

- 일러스트

- 코스트
일반 카드의 경우 코스트 표시 (원작 게임에서 "청휘석"이라는 용어 사용)
동아리 카드의 경우 인원수 표시 (사람 아이콘)
그 외의 경우 (상태이상 종족 같은 특성 카드) 아이콘 제외

- 무기 종류
(Front, Middle, Back 세 종류 입니다. 기존 UI에서는 AR로 표시되는 부분입니다.)

- 사거리

- 카드 종류 (학생 / 비학생 / 건물 / 이벤트)

- 소속 동아리 (기존 카드에서 "보충수업부 / 아리우스 스쿼드")
여러개가 될 수 있고, 없을 수 도 있으므로 각 경우를 모두 포함할 수 있는 디자인으로 부탁드립니다.

- 종족 (ex기계)
종족은 반드시 없거나 하나만 가집니다.

- 효과

- 공격력

- 체력

패 카드 UI 시 변경 사항
패 카드는 크기가 작고 호버링시 일부가 가려지므로 다음과 같은 변경사항을 적용하고자 합니다.
1. 무기 종류 및 사거리 제거

2. 일러스트는 중앙에 위치 가능하면 확대

3. 그럼에도 정보가 많아서 눈이 피로하다면 종족과 소속 동아리까지 가려도 될 것 같습니다.
