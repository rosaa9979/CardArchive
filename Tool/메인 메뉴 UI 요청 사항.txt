[전체 구성 안내]
- UI는 상단 탭바를 기준으로 하여, 선택한 탭에 따라 하단의 콘텐츠가 변경되는 탭 구조입니다.
- 배경은 일러스트 없이 단색 또는 그라데이션으로 구성해 주시면 됩니다. (인게임 UI의 양 진영 배경 색깔을 참고해 주셔도 좋습니다.)

[탭바 구성 요소]
- 프로필 사진 및 닉네임
- 탭 버튼:
  - 메인 메뉴 → 슬라이드 1번으로 연결됩니다.
  - 덱 에디터 → 슬라이드 3번으로 연결됩니다.
- 현재 선택된 탭은 색상을 다르게 하여 구분 가능하도록 부탁드립니다.

[슬라이드별 구성 안내]

■ 슬라이드 1 – 메인 메뉴
- 메뉴 구성 (각각 일러스트 포함 예정)
  - 스토리 모드
  - 싱글 모드
  - 멀티 플레이
  - 코드로 방 매치 (→ 클릭 시 슬라이드 2번으로 이동)

■ 슬라이드 2 – 코드로 방 매치
- 사용자가 원하는 사람과 매칭할 수 있는 기능입니다.
- 구성 요소:
  - 코드 입력창
  - 랜덤 코드 생성 아이콘
  - 참가 버튼
  - 뒤로 가기 버튼

■ 슬라이드 3 – 덱 에디터 (기본 구조)
- 카드 편집 기능을 위한 기본 UI입니다.
- 구성 요소:
  - 필터 (원하는 카드만 선별하여 보여주는 기능)
  - 마나 선택 필터는 UI상 적절한 방식이 마땅치 않아 제외한 상태입니다.
    → 디자이너님의 아이디어를 여쭙고자 합니다.
  - 카드 목록 (스크롤 방식)
  - 덱 목록 (덱 이름 나열)

■ 슬라이드 4 – 덱 추가하기
- 슬라이드 3의 확장 화면으로, 덱 목록 부분만 변경됩니다.
- 구성 요소:
  - 덱 이름
  - 편성된 동아리 아이콘
  - 카드 이름 / 매수 / 총 카드 수
  - 완성 버튼 및 뒤로 가기 버튼

■ 슬라이드 5 – 카드 상세 보기
- 카드 클릭 시 상세 정보를 확인할 수 있는 화면입니다.
- 구성 요소:
  - 카드 일러스트
  - 키워드 설명 (없는 카드도 있을 수 있습니다.)
  - 뒤로 가기 버튼

■ 슬라이드 6 – 선택 안내 창
- 첨부된 사진과 슬라이드 6을 참고해 주세요.


[기타 요청 사항]
- 일러스트는 별도로 원화가님께 요청드릴 예정이므로, 해당 자리를 확보해 주시고 해상도 및 규격을 알려주시면 감사하겠습니다.
- PPT 및 메모의 내용은 필수 구현 요소만 담고 있으므로, 형식(모양, 위치, 색상)에 얽매이지 않으셔도 될 것 같습니다.
- 필터 내 마나 표시 방식에 대해 디자이너님의 아이디어를 부탁드립니다.
