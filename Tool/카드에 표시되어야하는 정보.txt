카드에 표시되어야하는 정보
- 카드 이름

- 일러스트

- 코스트
일반 카드의 : 코스트 표시 (원작 게임에서 "청휘석"이라는 용어 사용)
동아리 카드 : 인원수 표시 (사람 아이콘)
그 외의 경우 (상태이상이나 종족 같은 특성 카드) : 아이콘 제외

- 무기 종류
(Front, Middle, Back 세 종류 입니다. 기존 UI에서는 AR로 표시되는 부분입니다.)

- 사거리

- 카드 종류 (학생 / 비학생 / 건물 / 이벤트 / 기타)
카드에 각 카드의 종류를 구별할 수 있는 기능을 가능하면 부탁드리겠습니다
기존 ui의 경우 일러스트 뒤의 살짝 회전해있는 사각형의 색깔을 다르게 해서 구별했습니다.

- 소속 동아리 (기존 카드 UI 중 효과 위에 적힌 "보충수업부 / 아리우스 스쿼드")
여러개가 될 수 있고, 없을 수도 있으므로 각 경우를 모두 포함할 수 있는 디자인으로 부탁드립니다.

- 종족 (ex기계)
여러개가 될 수 있고, 없을 수도 있으므로 각 경우를 모두 포함할 수 있는 디자인으로 부탁드립니다.
만약 불가능하다면 최대 한가지 종족만 가진다고 가정하고 디자인 하셔도 될 것 같습니다.
기존 카드 ui에서는 누락되어 있습니다.

- 효과

- 공격력

- 체력

카드 뒷면은 자유롭게 디자인 부탁드립니다.

패 카드 UI 시 변경 사항
패 카드는 크기가 작고 호버링시 일부가 가려지므로 다음과 같은 변경사항을 적용하고자 합니다.
1. 무기 종류 및 사거리 제거

2. 만약 일러가 한쪽으로 치우쳐 있다면, 일러스트는 중앙에 위치 가능하면 확대

3. 그럼에도 정보가 많아서 눈이 피로하다면 종족과 소속 동아리까지 가려도 될 것 같습니다.

기타
기존 ui는 신경쓰지 마시고 인게임 ui와 어울리게 디자인 하시면 될 것 같습니다.

새로 카드 디자인하면서 변경된 코스트, 공격, 체력, 사거리 아이콘이 인 게임 및 유닛 ui에 적용시켜주셨으면 좋겠습니다.
