# 데모 플레이 시나리오 — 어그로 관점

- 경기: `demo-showcase-20260914111522` / `root`(어그로) vs `Midrange`
- 어그로 동아리: 엔지니어부 · 트리니티 자경단 · 온천개발부
- 흐름: **초반 양쪽 공격로 압박 → 차단에 대응 → 건물 돌파 → 사거리 조절로 마무리**
- 결과: 어그로 8턴 승리, 선생님 체력 **8 : 0**.

아래 근거는 시나리오 주석과 실제 실행 기록을 바탕으로 정리했다. 좌표는 스크립트의 `(x,y)`이며, 턴 종료 후 공격은 자동으로 진행된다. 공격 대상을 직접 클릭해서 지정한 플레이로 해석하지 않는다.

## 어그로 덱 편성 소개

**저비용 기계로 빠르게 전개하고, 동아리 효과로 선생님 피해를 누적하며, 길을 막는 유닛·건물을 제거해 끝내는 덱**이다. 데모의 실제 편성은 동아리 3종과 메인 덱 20장으로, 학생 7장·기계 유닛 6장·공용 이벤트 7장이다.

### 세 동아리를 선택한 이유

| 동아리 | 선택 이유 | 편성한 학생 |
|---|---|---|
| **엔지니어부** | 기계가 죽어도 엔지니어부원 수에 따른 양 선생님 피해로 연결해, 저비용 기계의 교환을 공격 자원으로 활용한다. 내 체력도 소모하므로 장기전보다 빠른 마무리를 지향한다. | 우타하·코토리·히비키 각 1장. 우타하의 기계 소환, 코토리의 기계 속사 지원, 히비키의 범위 피해로 전개와 돌파를 보조한다. |
| **트리니티 자경단** | 적 유닛이 사거리 안에 있어도 선생님을 우선 공격해, 상대의 방어 유닛에 공격이 묶이는 상황을 줄인다. | 스즈미·레이사 각 1장. 스즈미의 제어 효과와 레이사의 적 위치 이동으로 상대 배치를 흔든다. |
| **온천개발부** | 건물로 공격로를 막는 수비에 대응한다. 부원이 장소를 공격하면 파괴하고 온천을 소환하므로, 높은 체력의 건물도 돌파할 수 있다. | 메구·카스미 각 1장. 메구의 주변 피해로 돌파하고, 카스미는 불리한 필드를 크게 정리할 수단으로 둔다. |

세 동아리는 **기계 교환 시 피해 누적 → 방어 유닛을 넘어 선생님 압박 → 건물 차단 해제**를 나누어 담당한다. 학생을 무작정 늘리기보다 공용 기계와 이벤트를 충분히 넣어 초반 전개와 공격로 확보를 뒷받침한다.

### 나머지 공용 카드 편성

| 역할 | 카드와 수량 | 편성 이유 |
|---|---|---|
| **초반 전개·기계 연계: 6장** | 스위퍼 **2장**, 개조 스위퍼 **2장**, 폭주하는 드론 **2장** | 스위퍼는 속사로 즉시 압박하고, 개조 스위퍼는 사거리 2와 하교 시 스위퍼 소환으로 후속 전력을 남긴다. 드론은 내 체력 3을 지불하는 대신 저비용 교전 전력을 제공한다. 기계 교환은 엔지니어부와 연결된다. |
| **단일·광역 제거: 4장** | C4 **2장**, 노노미, 총을 쏴 **2장** | C4는 핵심 유닛을 지정 제거하고, 노노미는 체력 1의 차단 유닛·토큰을 정리한다. 정의실현부처럼 재전개하는 상대에게는 단일 제거로 먼저 대응하고 광역기를 마무리 턴까지 남길 수 있다. |
| **결정타·공격 대상 조절: 2장** | 블루투스 권총 **2장** | 공격력 +2뿐 아니라 Front 무기 변경으로 사거리도 조절한다. 데모에서는 개조 스위퍼가 하나코 대신 선생님을 공격하도록 만들어 결정타를 낸다. |
| **학생 보충: 1장** | 당번 **1장** | 덱에서 무작위 학생을 뽑아 동아리 효과를 활용할 학생 전력을 보충한다. |

데모에서는 이 중 일부만 실제 사용한다. 코토리·히비키·레이사·카스미는 덱에 편성되어 있지만 경기 종료 전 사용하지 않았고, 당번은 8턴에 뽑은 뒤 남았다. 편성 목적과 실제로 보여준 장면은 구분한다.

## 턴별 행동과 근거

| 턴 | 어그로의 행동 | 판단 근거와 실제 전개 |
|---|---|---|
| **1** | 스위퍼를 **(2,3)**에 배치하고 종료. | 열린 왼쪽 공격로를 먼저 점유한다. 속사로 배치한 턴부터 상대 선생님에게 **1피해**를 준다. 처음부터 손에 들어온 블루투스 권총은 보관한다. |
| **2** | 우타하를 **(5,3)**에 배치하고, 천둥이 소환 위치로 **(6,3)**을 선택. | 오른쪽까지 전개해 상대가 양쪽을 방어하게 만든다. 기존 스위퍼는 왼쪽에서 계속 선생님을 공격한다. 상대는 히후미 **(6,4)**와 페로로 **(5,4)**로 오른쪽을 막는다. |
| **3** | 두 번째 스위퍼를 **(1,3)**에 배치. | 막힌 오른쪽에만 투자하지 않고 열린 왼쪽으로 압박을 분산한다. 스위퍼 둘은 선생님을 공격하고, 오른쪽 우타하·천둥이는 페로로·히후미와 교전한다. |
| **4** | 개조 스위퍼를 **(6,3)**에 배치. | 오른쪽에 사거리 2의 후속 전력을 준비하면서 왼쪽의 기존 스위퍼 둘로 피해를 누적한다. 이후 상대 정의실현부 토큰과 마시로가 왼쪽 스위퍼들을 제거해, 다음 턴에는 새 돌파 수단이 필요해진다. |
| **5** | 폭주하는 드론 **(1,3)**, 스즈미 **(2,3)** 배치. 스즈미의 대상으로 마시로 **(4,5)** 선택. | 드론으로 왼쪽 차단 유닛을 상대할 전력을 보충하고, 스즈미로 후방 마시로를 마비시킨다. 드론의 등교 효과로 내 체력 **3**을 지불한다. 개조 스위퍼는 오른쪽 히후미를 제거하지만, 상대가 마코토 동상 **(5,4)**으로 다시 길을 막는다. |
| **6** | 메구를 **(4,3)**에 배치. | 동상 옆에 온천개발부원을 준비해 다음 공격의 건물 파괴를 노린다. 드론은 왼쪽 정의실현부 토큰을 제거하고, 개조 스위퍼는 동상에 막힌다. 스즈미는 자경단의 선생님 우선 공격으로 **2피해**를 넣는다. 상대는 등교생으로 왼쪽을 다시 막는다. |
| **7** | C4를 마시로 **(4,5)**에 사용하고 종료. | 이 턴에 뽑은 노노미는 남기고 C4로 후방 위협만 제거한다. 상대 정의실현부는 유닛이 죽어도 토큰을 다시 만들므로, 광역기는 재전개 이후 마지막 공격로를 열 때 사용하려는 판단이다. 메구가 동상을 공격하면서 온천개발부 효과로 파괴하고, 주변 피해도 발생한다. 열린 오른쪽으로 개조 스위퍼가 선생님을 공격한다. 상대 체력은 턴 시작 **11 → 4**. 상대는 하나코·등교생으로 다시 방어하고, 반격 턴에 내 체력을 **16 → 8**로 낮춘다. |
| **8** | **노노미, 총을 쏴** 사용 → 개조 스위퍼 **(6,3)**에 **블루투스 권총** 사용 → 종료. | 아껴 둔 광역 1피해로 정의실현부 토큰 등 체력 1의 차단 유닛을 정리하고, 오른쪽 **(6,4)**의 등교생을 제거한다. 하나코 **(5,4)**는 살아 있지만, 권총으로 개조 스위퍼를 **Front·사거리 1·공격력 4**로 바꿔 사거리 2의 하나코가 공격 대상에 들어오지 않게 한다. 열린 길로 상대 선생님에게 **4피해**, 승리한다. |

## 보여주고 싶은 핵심 포인트와 실제 플레이

| 핵심 포인트 | 이를 보여주는 실제 장면 |
|---|---|
| **배치 위치가 공격로를 만든다.** | 1턴 왼쪽 **(2,3)**, 2턴 오른쪽 **(5,3)·(6,3)** 전개. 같은 유닛 수라도 어느 쪽에 놓느냐에 따라 선생님 공격과 유닛 교전이 갈린다. |
| **막힌 길을 뚫을지, 다른 길을 쓸지 선택한다.** | 3턴에는 오른쪽 히후미·페로로를 피해 왼쪽에 스위퍼를 추가한다. 양쪽이 막힌 5턴부터는 드론·개조 스위퍼로 차단 유닛을 제거하는 쪽으로 전환한다. |
| **소환 위치도 플레이어의 판단이다.** | 2턴 우타하의 천둥이를 **(6,3)**에, 상대 히후미의 페로로를 **(5,4)**에 배치해 공격 전선과 도발 방어선을 구성한다. |
| **사거리와 공격 우선순위는 서로 다른 전략 요소다.** | 개조 스위퍼는 사거리 2의 적을 공격한다. 반면 6턴 스즈미는 트리니티 자경단 효과로 사거리 안의 적 유닛보다 선생님을 우선 공격한다. |
| **동아리가 덱의 운영 방식을 바꾼다.** | 초반 기계 교환에서는 엔지니어부의 사망 연계 피해, 6턴에는 자경단의 선생님 우선 공격, 7턴에는 온천개발부의 건물 파괴를 보여준다. 유닛 스탯 외에 동아리 조합이 승리 경로를 만든다. |
| **내 체력을 전개 자원으로 사용할 수 있다.** | 5턴 폭주하는 드론의 등교 효과로 내 선생님에게 3피해를 감수한다. 드론은 이후 왼쪽의 정의실현부 토큰·등교생과 교전하는 전력이 된다. |
| **제어 효과로 준비할 시간을 확보한다.** | 5턴 스즈미가 후방 마시로를 마비시킨다. 이후 6턴에는 건물 돌파용 메구를 준비하고, 7턴에는 C4로 마시로를 제거한다. |
| **건물은 공격을 받아내며, 전용 대응 수단이 있다.** | 상대가 5턴 마코토 동상으로 오른쪽을 막고, 6턴 개조 스위퍼의 공격을 받아낸다. 7턴 메구는 온천개발부 효과로 건물의 남은 체력을 깎아 끝낼 필요 없이 파괴한다. |
| **제거 효과와 상대의 사망 연계가 함께 전개된다.** | 7턴 C4·메구의 공격과 주변 피해로 유닛을 제거하지만, 상대 정의실현부는 부원 토큰을 다시 만든다. 상대도 등교길에서 얻은 등교생 등을 재전개해 한 번 뚫린 길을 다시 막는다. |
| **상대 동아리에 맞춰 제거기의 사용 시점을 조절한다.** | 정의실현부의 사망 후 토큰 재소환을 보고 광역기를 서둘러 소모하지 않는다. 실제로 7턴에 뽑은 노노미는 보관하고 C4로 마시로만 제거한다. 상대의 토큰 재소환·재전개가 진행된 뒤 8턴에 광역 정리와 마무리 공격을 한 턴에 연결한다. |
| **광역 피해는 공격로를 여는 수단이다.** | 8턴 노노미는 적을 전부 없애기보다 체력 1의 차단 유닛을 정리한다. 하나코가 남아 있어도 마지막 공격을 연결할 여건을 만든다. |
| **사거리가 짧아지는 것이 오히려 유리할 수 있다.** | 8턴 블루투스 권총으로 개조 스위퍼의 사거리를 2에서 1로 줄인다. 하나코와 교전하는 대신 선생님을 공격하게 만드는, 이 시나리오의 결정적인 판단이다. |
| **카드를 아껴 둔 이유가 마지막에 드러난다.** | 블루투스 권총은 첫 턴부터 8턴까지, 노노미는 뽑은 7턴에서 8턴까지 남긴다. 노노미로 길을 열고 권총의 공격력 +2와 무기 변경을 함께 활용해 상대의 남은 체력 4를 정확히 끝낸다. |
| **자동 전투의 결과를 행동 순서로 설계한다.** | 6턴 메구 준비 → 7턴 건물 파괴, 8턴 광역 정리 → 무기 변경 → 턴 종료. 승부는 공격 순간의 수동 조작보다 그 전에 만든 배치·대상·사용 순서에서 결정된다. |
| **상대의 압박 속에서 승리 시점을 계산한다.** | 상대 7턴에 코하루 7피해와 정의실현부 부원 1피해를 받아 내 체력이 8이 된다. 수비를 더 쌓기보다 남은 공격로와 손패 두 장을 이용해 다음 턴에 끝낸다. |

**전달하려는 메시지:** 카드를 많이 내는 것만으로 이기는 게임이 아니라, **배치·사거리·동아리 효과·상대 동아리에 따른 대응·사용 순서를 조합해 자동 전투가 원하는 결과를 내도록 만드는 게임**이다.
