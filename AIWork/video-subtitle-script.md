# 카드 아카이브 — 전체 영상 자막 대본

기준: `video-editing-guideline.md`, `demo-scenario.md`, 게임 씬 입장부터 시작하는 인플레이 v3.

내레이션 없이 자막으로 설명하는 대본이다. 질문·답변 유도·시청자에게 선택을 요청하는 표현은 사용하지 않는다. 아래 번호 한 개를 자막 한 화면으로 사용하며, 두 문장이 있는 경우 두 줄로 나눈다. 설명 분량에 따라 한 문장씩 순차 표시해도 된다.

자막은 페이퍼로지 Regular, 하단 영역 가로 중앙 정렬. 좌측 상단 턴 표기는 페이퍼로지 7 Bold를 사용한다. 게임 안에 녹화된 UI 문구는 이 대본의 자막과 구분한다.

## 1. 게임 소개 — 권장 30~45초

1. 카드 아카이브는 블루 아카이브의 캐릭터와 동아리를 활용한 카드 전략 게임입니다.
2. 동아리를 조합해 덱의 운영 방향을 정하고, 카드를 배치해 전투를 준비합니다.
3. 유닛의 위치와 사거리를 조절하며 상대 선생님의 체력을 0으로 만드는 것이 목표입니다.
4. 턴을 마치면 준비한 필드에서 자동 전투가 진행됩니다.

화면 타이틀: **카드 아카이브 / Card Archive**

제작 메모 — 위 소개와 별도로 원작 IP 및 실제 허가 공지 카드를 배치한다. 허가 원문은 제공된 문서에서 확인되지 않아 대사를 작성하지 않았다. 확보한 원문을 넣고 읽을 시간을 별도로 확보한다. 이 메모는 화면 자막으로 사용하지 않는다.

## 2. 규칙 소개 — 권장 1분~1분 30초

### 손패와 카드

1. 손패와 비용을 관리하며 카드를 사용하는 턴제 카드게임에 슬롯 배치와 자동 전투를 결합했습니다.
2. 카드의 비용을 지불해 유닛을 배치하거나 이벤트 효과를 사용합니다.
3. 학생과 비학생 유닛은 필드에서 전투하며 각자의 능력과 특성을 활용합니다.
4. 장소와 건물은 필드에 남아 공격로와 배치에 영향을 줍니다.
5. 이벤트는 피해, 강화, 무기 변경과 같은 효과를 적용합니다.
6. 동아리는 덱의 운영 방향과 학생 사이의 조합을 결정합니다.
7. 카드에는 비용, 공격력, 체력, 무기와 사거리, 효과가 표시됩니다.

### 필드와 턴 진행

8. 필드는 아군 구역, 중립 구역, 적 구역으로 나뉩니다.
9. 유닛의 위치에 따라 공격할 수 있는 상대와 선생님에게 닿는 길이 달라집니다.
10. 장소 카드 역시 배치할 수 있는 위치가 정해져 있습니다.
11. 메인 페이즈에는 카드를 사용하고, 유닛을 배치하며, 카드 효과에 필요한 대상을 선택합니다.
12. 턴을 마치면 공격 페이즈가 시작되고, 정해진 순서와 규칙에 따라 공격이 자동으로 진행됩니다.
13. 공격이 끝나면 상대 턴으로 넘어갑니다.

화면 도식: **메인 페이즈 → 턴 종료 → 공격 페이즈 → 상대 턴**

## 3. 차별점 소개 — 권장 2분~2분 30초

### 동아리로 만드는 덱의 전략

1. 동아리 시스템은 원작의 관계를 덱 구성과 플레이 판단으로 연결합니다.
2. 개별 카드의 능력에 더해, 함께 사용할 동아리의 조합으로 전략을 만듭니다.
3. 이번 어그로 덱은 엔지니어부, 트리니티 자경단, 온천개발부를 조합합니다.
4. 엔지니어부는 기계가 쓰러지는 상황을 선생님 피해로 연결합니다.
5. 트리니티 자경단은 선생님을 우선 공격해 압박을 이어갑니다.
6. 온천개발부는 건물을 파괴해 막힌 공격로를 엽니다.
7. 공용 카드도 함께 사용하는 동아리에 따라 맡는 역할이 달라집니다.
8. 상대 동아리의 특성은 대응 카드를 사용할 시점을 판단하는 근거가 됩니다.
9. 정의실현부는 유닛이 쓰러지면 토큰을 보충합니다.
10. 이 경기에서는 상대의 재전개에 대응하기 위해 광역기를 남겨 두는 판단이 중요합니다.

강조 자막: **동아리 조합으로 덱의 운영 방향을 결정합니다.**

### 준비와 공격을 나눈 전투

11. 슬롯이 많아지면 유닛의 위치를 고르는 선택도 다양해집니다.
12. 모든 공격을 직접 지시하는 조작은 줄이고, 배치와 카드 사용의 판단에 집중하도록 준비와 공격을 분리했습니다.
13. 플레이어는 메인 페이즈에서 필드를 준비하고, 공격 페이즈에서 그 결과를 확인합니다.
14. 카드 효과의 대상은 직접 선택하지만, 일반 공격의 대상은 전투 규칙에 따라 정해집니다.

강조 자막: **카드와 배치로 준비하고, 자동 전투로 결과를 확인합니다.**

### 공격 후보를 조절하는 판단

15. 시스템은 사거리와 공격 가능 여부를 확인하고, 건물과 도발 등의 우선순위를 적용합니다.
16. 동아리와 능력에 따른 예외를 반영한 뒤에도 후보가 여럿 남으면 무작위로 선택합니다.
17. 배치를 바꾸고, 사거리를 조절하고, 방해 유닛을 제거하면 공격 후보가 달라집니다.
18. 같은 우선순위의 두 대상만 후보로 남은 예시에서는 각 대상의 선택 확률이 절반입니다.
19. 한 대상만 후보에 남기면 그 대상이 선택됩니다.
20. 이는 공격 대상의 선택을 뜻하며, 회피나 이후 효과까지 보장하는 것은 아닙니다.
21. 선생님을 노릴 때도 공격로를 막는 유닛과 사거리를 함께 고려합니다.
22. 원하는 공격이 이어지도록 조건을 만드는 것이 전투 준비의 핵심입니다.

강조 자막: **배치·사거리·제거 → 공격 후보 조절**

제작 메모 — 18~20번은 가이드라인의 별도 검증된 단순 예시 필드에 붙일 자막이다. 현재 인플레이 영상에 임의의 확률 수치를 추가하지 않는다. 기획 의도는 사용자 테스트로 검증된 성과처럼 표현하지 않는다.

## 4. 예시 플레이 — 어그로

### 4-1. 덱 소개 카드 — 플레이 시작 전 별도 화면

1. 이 덱은 저비용 기계로 초반을 압박하고, 동아리 효과로 유닛과 건물의 방어를 돌파합니다.
2. 스위퍼, 개조 스위퍼, 폭주하는 드론이 초반 전개와 교환을 담당합니다.
3. C4는 핵심 유닛을 제거하고, 노노미는 여러 차단 유닛을 함께 정리합니다.
4. 블루투스 권총은 공격력과 사거리를 조절하고, 당번은 학생을 보충합니다.
5. 학생 7장과 공용 카드 13장으로 메인 덱 20장을 구성합니다.
6. 상대의 정의실현부가 토큰을 보충하므로, 광역기의 사용 시점을 조절합니다.

별도 고지: **시스템 설명을 위한 구성된 시연 경기입니다. 덱 순서와 무작위 결과를 고정했습니다.**

제작 메모 — 덱 소개와 고지는 게임 씬 입장 2초에 몰아넣지 않고 앞의 소개 화면에서 충분히 표시한다. 아래 플레이 타임코드는 별도 소개를 포함하지 않은 v3 영상 기준이다.

- 8턴 범위 설명: **하나코 · 사거리 밖**, **선생님으로 공격 연결**
- 정지 화면의 범위와 화살표: **편집용 설명 표시**

실제 자동 공격 구간에서는 설명용 범위와 화살표를 걷는다. 위 강조 문구는 하단 자막과 동시에 모두 표시하지 않고 해당 장면에 필요한 항목만 사용한다.

## 5. 마무리 — 권장 20~30초

1. 열린 공격로를 활용하고, 건물을 파괴하고, 사거리를 조절하며 마지막 공격을 준비했습니다.
2. 상대 동아리의 재전개를 예상해 남겨 둔 광역기가 승리로 이어졌습니다.
3. 카드 아카이브는 동아리로 전략을 만들고, 배치와 사거리로 전투를 설계하는 게임입니다.
4. 상대의 구성을 읽고 어떤 카드를 언제 사용할지 판단하는 재미를 담고자 했습니다.

마지막 타이틀: **동아리로 전략을 만들고, 배치로 전투를 설계한다.**

제작 메모 — 공개 일정, 개발 현황, 피드백 경로는 확정된 자료가 없어 추가하지 않았다. 앞의 1~3장과 덱 소개, 마무리는 추가 화면 구성이 필요한 전체 영상용 대본이다. 플레이 부분만 현재 v3에 맞춘 SRT를 별도로 제공한다. 이 문서 작성으로 기존 MP4에 대사가 반영되지는 않는다.
